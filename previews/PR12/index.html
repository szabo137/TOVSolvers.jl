TOVSolvers

TOVSolvers.jl is a Julia package for solving the Tolman–Oppenheimer–Volkoff (TOV) equations with linear affine equations of state. It provides a common interface for multiple coordinate systems, initial conditions, event callbacks, and numerical solver configurations.

Installation

Install from the Julia REPL:

using Pkg
Pkg.add(url="https://github.com/szabo137/TOVSolvers.jl")

Quickstart

using TOVSolvers

coord_sys = MMprimeSystem()
params = TOVParameters(
    1.0,                # omega
    3.0                 # x
)

initial_condition = RegularOrigin(
    coord_sys,
    1e-16,              # r_initial
    0.0,                # m_initial
    1.0                 # m_prime_initial
)

problem = TOVProblem(
    params,
    initial_condition,
    10.0;               # r_final
    direction=:forward,
)

config = TOVSolverConfig(
    abstol=1e-10,
    reltol=1e-10,
)

solution = solve(problem, config)

Inspect the result:

reached_horizon(solution)
reached_origin(solution)
classify_solution(solution)
